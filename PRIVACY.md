# Soukromí

**Kaskáda neukládá o hráčích žádná data na žádný server.**

- Postup (XP, hvězdy, úspěchy, rozpracovaný kód) se ukládá jen do `localStorage` ve tvém prohlížeči. Smažeš ho tlačítkem „Smazat postup“ v profilu nebo vymazáním dat stránky v prohlížeči.
- Záloha postupu je soubor, který si stáhneš ty. Nikam se neposílá.
- Hra nepoužívá cookies, analytiku ani sledovací skripty. Písma jsou hostovaná přímo na webu, ne u Googlu.
- Tlačítko „Zkopírovat zadání pro AI“ jen zkopíruje text do tvé schránky. Kam ho vložíš, je na tobě.
- **Galerie** používá [giscus](https://giscus.app) — komentáře uložené v GitHub Discussions tohoto repozitáře. Načte se, až když otevřeš záložku Galerie. Komentovat můžeš jen po přihlášení svým GitHub účtem; tvoje údaje v tom případě zpracovává GitHub podle [svých podmínek](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement), ne autoři Kaskády.
- Web běží na GitHub Pages; GitHub může jako provozovatel hostingu logovat technické údaje (např. IP adresu) — viz jeho [prohlášení o ochraně soukromí](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
